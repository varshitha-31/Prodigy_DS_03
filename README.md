# PRODIGY_DS_03
## Decision Tree Classifier for Customer Purchase Prediction

## 📌 Overview
This project was completed as part of the **Prodigy InfoTech Data Science Internship – Task 03**.

The objective of this task is to build a **Decision Tree Classifier** that predicts whether a customer will purchase a product or service based on demographic and behavioral data. The model is trained using the **Bank Marketing Dataset** from the UCI Machine Learning Repository.

---

## 🎯 Objective
- Build a Decision Tree Classification model.
- Preprocess and prepare the dataset.
- Train the model using customer information.
- Evaluate model performance.
- Visualize the Decision Tree and Confusion Matrix.

---

## 📂 Dataset
**Dataset:** Bank Marketing Dataset

Features include:
- Age
- Job
- Marital Status
- Education
- Default
- Housing Loan
- Personal Loan
- Contact Type
- Campaign
- Previous Outcome
- Subscription Status (Target Variable)

## 📊 Project Workflow

### 1. Import Libraries
Imported all required Python libraries.

### 2. Load Dataset
Loaded the Bank Marketing dataset into a Pandas DataFrame.

### 3. Data Preprocessing
- Checked missing values
- Removed duplicates
- Encoded categorical variables
- Split features and target variable

### 4. Train-Test Split
Split the dataset into training and testing sets.

### 5. Model Building
Implemented the Decision Tree Classifier using Scikit-learn.

### 6. Model Evaluation
Evaluated the model using:
- Accuracy Score
- Confusion Matrix
- Classification Report

### 7. Visualization
Generated:
- Decision Tree
- Confusion Matrix
- Feature Importance
